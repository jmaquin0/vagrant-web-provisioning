Taller: Vagrant de Provisionamiento

Descripción
Proyecto de práctica para crear y configurar máquinas virtuales con Vagrant.
Se implementan dos máquinas:
- web: con Apache y PHP
- db: con PostgreSQL


Pasos
1. Clonar el repositorio.
2. Ejecutar vagrant up web y vagrant up db.
3. Acceder desde el navegador:
   - `http://192.168.56.13` → Página HTML
   - `http://192.168.56.13/info.php` → Datos desde PostgreSQL
